# 02: Pomodoro timer with notifications and Overtime

**What to build:** A Pomodoro timer, optionally for one Task, that keeps running with the window closed (spec stories 16–20, 22).

**Blocked by:** None

**Status:** ready-for-agent

**Implementation:** in progress — Draft PR

## Acceptance criteria

- [x] Durations default to 25 / 5 / 15 (long break after every 4 sessions) and are adjustable and remembered. _Evidence: `PomodoroDurations::default()` and limits (focus 1–180, breaks 1–60, long break after 1–12) in `crates/tasknotes-core/src/pomodoro.rs` (`defaults_are_25_5_15_with_a_long_break_after_4`, `durations_outside_the_limits_are_refused`, `every_fourth_finished_session_earns_a_long_break`, `stopped_sessions_do_not_count_toward_the_long_break`, `adjusted_durations_apply_from_the_next_focus`). Kept in `shell-settings.json` beside the database (`shell_settings.rs` round-trip; `shell_state.rs` `pomodoro_lengths_are_checked_saved_and_remembered`, failed save changes nothing). Settings › Pomodoro: `src/pomodoro.test.tsx` shows 25/5/15/4, saves 50, refuses 0 before asking the shell._
- [ ] A session can be started with or without a Task; the menu bar shows time left while running and "🍅 Done" after focus ends until the owner responds. _Evidence (logic): start with no Task or an unfinished one, open Task offered first (`src/pomodoro.test.tsx`); menu bar text from the core timer: "🍅 25:00", "🍅 12:34", rounded-up "🍅 00:01", "🍅 Done" held until a click (`a_focus_counts_down_in_the_menu_bar_and_shows_done_at_its_end`, `the_focus_end_is_announced_once_and_then_waits_for_a_click`). Timer ticks in the Rust shell; the session's own title-only menu-bar item exists while the timer is not Idle, whatever Keep in menu bar says, and closing the window then hides it (`close_action` tests). **Open: native check that the item and its title show in the real menu bar with the window closed.**_
- [ ] Focus end delivers one macOS notification, silent in Silent mode, with Start break and Keep focusing; every switch waits for a click. _Evidence (logic): exactly one notification per focus end through the `Effects` seam, silent flag passed (`pomodoro_state.rs` `the_focus_end_sends_exactly_one_notification`, `in_silent_mode_the_notification_has_no_sound`); every switch waits (`every_switch_waits_for_a_click`, stale notification clicks ignored). tauri-plugin-notification 2.8.0 shows desktop actions (macOS puts two in an Options menu; a click on the notification opens the window); the same choices are in the menu-bar item and the sidebar. Silent mode = the window's interaction sounds muted (see comments). **Open: native check of delivery, sound, the Options menu and both actions.**_
- [x] Keep focusing counts Overtime from the planned end ("🍅 +mm:ss") until Start break or Stop; choosing Start break directly counts no waiting time. _Evidence: core `keep_focusing_counts_overtime_from_the_planned_end` ("🍅 +02:15", 7 min 10 s stored), `start_break_straight_from_the_end_counts_no_waiting_time` (10 min wait → 0), `stopping_during_overtime_keeps_the_session_finished_with_its_overtime`, `stopping_at_done_finishes_the_session_without_overtime`; window shows the same "+02:15" (`src/pomodoro.test.tsx`)._
- [x] A finished session tied to a Task adds one Progress Entry ("Pomodoro: 25 + N min focus") and never changes status; a Stopped session adds none. _Evidence: `crates/tasknotes-core/tests/pomodoro.rs`: In Progress stays In Progress at 40% with note "Pomodoro: 25 + 7 min focus"; Ready stays Ready ("Pomodoro: 25 min focus" when no Overtime); a Task Completed mid-session stays Completed; Stopped adds none; a Task in Removed keeps the session without an entry; one transaction with `task.progress` and `pomodoro.record` Audit Entries. The window re-reads Tasks when the shell reports the change._
- [ ] On first use, if the notification style is not Persistent, a one-time tip opens the Tasknotes page in System Settings; the exact macOS label is verified on the owner's Mac. _Evidence (logic): the alert style is read with `UNUserNotificationCenter` (`notification_style.rs`; the plugin does not expose it), only inside a bundled `.app` (elsewhere it returns unknown instead of crashing; tested). Due once unless Persistent, unknown counts as not Persistent, remembered across restarts (`the_notification_tip_is_due_once_unless_the_style_is_persistent`); button opens `x-apple.systempreferences:com.apple.Notifications-Settings.extension?id=store.adamaja.tasknotes`; `src/pomodoro.test.tsx` first start shows it, second does not ask. **Open: native check of the style read, the link and the macOS label.**_
- [x] Sessions are stored in the core with start, planned length, Overtime, outcome (finished / stopped) and optional Task. _Evidence: schema v22 `pomodoro_sessions` (append-only triggers, CHECKs: Stopped has no Overtime, end ≥ start); `record_pomodoro_session` (desktop only) and `list_pomodoro_sessions(from, to)` / `get_pomodoro_session` for Ticket 14 (readable by every interface). `tests/pomodoro.rs` 13 tests incl. refusal of impossible sessions, unknown Task, rewrite attempts, v19 → v22 upgrade._
- [x] Ambient rain is unaffected by Pomodoro. _Evidence: `src/pomodoro.test.tsx` `leaves Ambient rain playing at its level through a whole session` (same source, never stopped, 8%); the Pomodoro code never imports the sound engine; the notification sound is the system's._

**2026-11-09 — implementation notes (AI), Draft PR:**
- Schema **v22** (v20/v21 are Tickets 13 and 12): one self-contained step, `migrate_v22`, touching only its own table. Older test fixtures that roll a database back now drop `pomodoro_sessions` too.
- Timer: a pure state machine in the core (`tasknotes_core::pomodoro::PomodoroTimer`, every step takes `now`), driven by a one-second tick thread in the Rust shell (`src-tauri/src/pomodoro.rs`), so it survives a closed window. `pomodoro_state.rs` holds the shell rules behind an `Effects` seam (notification, store); tests never fire a real notification.
- Menu bar: chosen approach is a **second, title-only menu-bar item** that exists only while the timer is not Idle, independent of "Keep Tasknotes in the menu bar" (which keeps its meaning). While it is there, closing the window hides it instead of quitting. Quitting with ⌘Q during a session ends it without storing it.
- Decisions made without the owner (say if you prefer otherwise): **Silent mode = interaction sounds muted in Tasknotes** (macOS Focus also silences on its own); Stop during Done or Overtime counts as **Finished** (the session reached its planned end, per the Glossary), only Stop before the end is Stopped; the progress note rounds Overtime to the nearest minute and drops "+ 0"; breaks show "☕ mm:ss" / "☕ Done" and the break end sends **no** notification (the spec names only the focus end); the menu bar's Start focus reuses the last Task; the timer is desktop-only to write, readable by all interfaces.
- Notification: `tauri-plugin-notification` 2.8.0, used from Rust only (no JS permission; capabilities still `core:default`). New macOS notification permission. Sound: the system default unless Silent.
- Still open: native checks (menu bar item and titles with the window closed, notification delivery/sound/actions, alert-style read and System Settings link), with the screen awake and synthetic data. CLI/MCP read of sessions waits for Ticket 14.
