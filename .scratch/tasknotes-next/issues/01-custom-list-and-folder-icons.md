# 01: Icons and colours for Lists and Note Folders

**What to build:** Let the owner give each List and Note Folder an icon and a colour (spec stories 15).

**Blocked by:** 04 (manual sidebar order, PR #24), 11 — Sidebar hover, width and action icons

**Status:** ready-for-agent

**Implementation:** in progress — Draft PR

## Acceptance criteria

- [x] Each List and Note Folder can have one icon and one of 12 colours; both optional, default unchanged look. _Evidence: schema v19 (v18 left to Ticket 10) adds nullable `icon`/`color` to `lists` and `note_folders`; `crates/tasknotes-core/src/style.rs` validates against `style.json` (12 colour keys, 251 Lucide names) and writes through `set_list_style` / `set_note_folder_style` (revision +1, `list.style` / `folder.style` Audit Entries, stale refusal audited). `tests/style.rs` (12 tests: default look, set/clear/keep, unknown names, empty, unchanged, stale, Removed, restoring a Removed List or Note Folder keeps its Style, upgrade from v17 leaves revisions untouched and every older row NULL); `backup_restore.rs` restores a pre-v19 backup with every List back to the default look. UI: `src/style-picker.test.tsx` shows the chosen icon in its colour and the default folder otherwise. Native GUI not checked._
- [x] The 12 colours meet AA contrast as icon colour on the sidebar in light and dark themes. _Evidence: `--style-<key>` tokens per theme in `App.css`; `src/style-picker.test.tsx` checks all 72 pairs at ≥ 3:1 (WCAG 1.4.11, graphical object) on sidebar, hover yellow and folder-selected gray (lowest: dark red 3.86 on hover/selected; light yellow 3.81 on selected); each is also ≥ 4.5:1 on the plain sidebar. Picker rules are registered in `a11y-contrast.test.tsx`._
- [x] The picker offers the app's Lucide icons with a search box; choosing is keyboard accessible. _Evidence: "Icon and colour for …" row action (inside the opaque action overlay) opens an inline picker: "Colour" and "Icon" radio groups (one tab stop each, arrows move and choose across and down, Home/End), "Search icons" (word-prefix search, Down enters the icons), Save/Cancel, Escape cancels and focus returns to the row. The picker spans the sidebar's full width at any folder depth; its grids keep cells ≥ 22px and wrap at a narrow sidebar, the arrows following the row as laid out; while saving, focus stays on Save (picker `aria-busy`, controls `aria-disabled`, not `disabled`). `src/style-picker.test.tsx` mouse, keyboard, clear and refusal tests, plus Note Folders. Bundle: curated, tree-shaken set (`src/lib/style-icons.ts`, generated by `pnpm gen:style-icons`; a test keeps it equal to `style.json`); main chunk 371.66 → 456.06 kB (gzip 113.53 → 141.07 kB)._
- [x] Emoji already in names are not changed or stripped. _Evidence: core `emoji_names_stay_as_typed_and_a_rename_keeps_the_look`; CLI and MCP tests style "🏠 Synthetic home" and read the name back unchanged; UI test renders "🏠 Home" with its icon._
- [x] CLI and MCP can read and set icon and colour with revision checks; exports include them. _Evidence: CLI `list|folder style ID --revision N [--icon NAME|none] [--color NAME|none]` and `style options` (`crates/tasknotes-cli/tests/style.rs`, 3 tests); MCP `list_style`, `folder_style` (null clears, left out keeps) and `style_options` (`crud.rs` `icons_and_colours_are_read_set_and_cleared_through_mcp`; tool count 45). List and folder output carries `icon` and `color`. JSON export: `json_exports_include_each_icon_and_colour`._

**2026-11-09 — implementation notes (AI):**
- Name: the pair is a **Style** (GLOSSARY), not "appearance", which already means the light/dark theme.
- One allow-list: `crates/tasknotes-core/src/style.json`. The core embeds it (`include_str!`) and refuses anything else; the window imports the same JSON for the picker, and `scripts/gen-style-icons.mjs` writes the icon import map from it (a Vitest keeps them equal). Chosen over an IPC call because the window needs the icon components at build time anyway, and over a hard-coded TS list because that would be a second copy.
- The columns carry no CHECK on the names (only a length bound), so adding an icon later needs no migration; the core is the gate.
- Palette: Apple's twelve system colour names, tuned per theme for contrast.
- Icons are imported eagerly (the sidebar needs them at launch); 251 icons cost about 84 kB raw / 27 kB gzip in the main chunk. Lazy-loading them would flash the default icon at launch.
- Open: native GUI check in the built app (both themes, narrow sidebar), not done here.
