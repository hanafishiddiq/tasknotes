# Triage labels

These five roles are the canonical labels used by the Matt Pocock skills. In our local Markdown tracker, write the selected label as the issue's `Status:` value.

| Canonical role | Local tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Incoming issue needs assessment |
| `needs-info` | `needs-info` | Waiting for required information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready to implement |
| `ready-for-human` | `ready-for-human` | Requires action or decision by a person |
| `wontfix` | `wontfix` | Deliberately not proceeding |

This file maps triage role labels. Tickets may additionally track their implementation progress separately; do not misuse `wontfix` as a completion state.
